# Required technology

Always use:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Motion for React
- Lenis where smooth scrolling is needed
- Lucide React icons

# Styling rules

- Tailwind CSS must be used for component styling.
- Do not use CSS modules.
- Do not use styled-components.
- Do not use Bootstrap.
- Do not use component libraries unless explicitly requested.
- Do not use inline style objects unless values must be calculated dynamically.
- Reuse design tokens from globals.css.
- Avoid excessive border radius.
- Avoid glassmorphism.
- Avoid purple AI gradients.
- Avoid generic SaaS cards.
- Avoid large glowing backgrounds.
- Keep the interface industrial, editorial and technical.

# Code quality

- Use strict TypeScript.
- Do not use `any`.
- Use semantic HTML.
- Keep components focused and reusable.
- Avoid files larger than approximately 250 lines when practical.
- Keep content separate from presentation using data files.
- Use Next.js Link for internal navigation.
- Use Next.js Image for portfolio images.
- Use accessible labels and keyboard interactions.
- Respect prefers-reduced-motion.
- Use transform and opacity for animation where possible.
- Disable cursor effects on touch devices.
- Avoid unnecessary client components.
- Add "use client" only when browser APIs, event listeners or Motion hooks require it.
